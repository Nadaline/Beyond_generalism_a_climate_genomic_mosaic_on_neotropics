This is a strong source/output correspondence, not a claim of bitwise regeneration: I did not rerun the script.

The script reads saved `GF_present_landscape.tif` and `RDAforest_present_landscape.tif`, two visualization-PCA objects, a present-day RDA raster template, original CHELSA BIO1–BIO7/BIO12/BIO13/BIO15 rasters, and the individual environmental table. The upstream `build_nonlinear_present_landscapes.R` uses 32 controlled full-panel GF batch objects and the saved main eight-PC RDAforest fit/predictions; it does not fit either model again. The Figure 4 script correlates analytical PC1 scores with original present-day climate and uses those results for the insets.

For panel b only, it bilinearly resamples the native RDAforest surface to a 0.10-degree display grid and masks it to land. It writes `RDAforest_present_landscape_bilinear_display_only.tif`. The analytical RDAforest raster, PC scores, correlations and reported statistics remain based on the native prediction cells; bilinear pixels are not extra independent model predictions. The GF map is displayed at its existing raster resolution. The manuscript caption should preserve this distinction.

The finishing script and both figure exports are imported into this private branch. Its saved rasters, PCA/model objects, climate rasters and exact sampling table remain external. Machine-specific paths in the unmodified script still require a reviewed portability correction before public release.
