# Data and reproducibility records

This public repository accompanies Chapter 1 of the thesis and will be updated as the related publications progress. The [reproduction guide](reproducibility.md) describes which steps can currently be repeated; the [technical notes](technical_reproduction_notes.md) retain more detailed inputs and settings.

Further documentation will connect the available figures to the original fitted objects, document the full read-to-genotype procedure and the climate data downloads, and provide a versioned data accession where permitted. These additions will not change the manuscript results without a corresponding scientific explanation.
