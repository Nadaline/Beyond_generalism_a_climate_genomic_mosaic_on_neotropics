# Figure 5 projection and domain audit

The earlier finishing source is `scripts/build_Figure5_genomic_offset_final.R` (original source SHA-256 `4a218cb652615adbc4ce78b59bedadb28bb33f3a78f9650c7ca15da5603d68ad`). Its named PDF/PNG exports were saved seconds after the script and are consistent with its four-panel layout. The source documents the earlier four-panel offset export.

The script reads the saved 626-strict-candidate, climate-only RDA projection-offset rasters (`19_RDA_offset_mid_century.tif`, `19_RDA_offset_late_century.tif`), the controlled full-panel GF future-offset rasters from the 14,134-SNP/ten-predictor fit, and `21_RDAforest_original_offset_pixels.csv` from the main genome-wide RDAforest lineage. It samples RDA/GF at the existing RDAforest evaluation grid and calculates method-specific percentile ranks. The RDA projection model is not the main conditioned 14,134-SNP partial RDA. Correlations in this finishing script use original displacement magnitudes on the shared valid cells, while the maps show ranks.

**Substantive display conflict.** The saved late-century audit reports 4,507 RDA-valid cells, 2,529 GF-valid cells, 4,515 RDAforest-valid cells and 2,529 shared-valid cells. The Figure 5 script fits a spatial GAM to valid GF ranks and fills the other 1,986 late-century GF cells in `GF_display_rank`; panel b plots this filled column. The spatial-agreement panel and correlations still use the 2,529-cell shared mask. Thus panel b is visually complete across unsupported GF climate space and must not be described as a masked supported projection. This interpolation is display-only, not a GF model fit, but it can mislead readers. The 2041–2070 GF panel uses unfilled `GF_rank`.

The upstream full-panel GF projection script endpoint-clamps ECDF and cumulative-importance curves **within** a permitted domain, excludes cells where any of ten predictors exceeds the observed range by more than 20% of that predictor's range, and intersects present/future validity. The RDA/RDAforest rasters use their own saved domains. A separate domain-rule audit reports 2,788 theoretically valid late-century GF cells under its reconstructed rule, whereas the actual saved GF offset used here has only 2,529 valid RDAforest-grid cells. The finishing files alone do not resolve this difference.

The climate inputs have filenames such as `CHELSA_bio2_2071-2100_SA.tif`, 1/120-degree WGS84 pixels and only generic raster metadata. The available records contain no verifiable GCM or SSP in the inspected filenames, raster attributes or nearby text manifests. Their exact source remains unconfirmed. The core projection code crops to −85…−30° longitude and −35…15° latitude, aggregates by five and uses a land mask from `maps::world`; the available records do not establish a Map of Life native-range polygon in the final input chain. Figure 5 uses `maps::world` as a display outline; this is not evidence of a native-range mask.

The earlier late-century exports are not included here. A supported-domain display would plot `GF_rank` with missing values outside support, retain the shared-valid agreement calculation and identify excluded cells in the caption. The 2,529-versus-2,788 domain discrepancy and climate-source metadata remain unresolved.
